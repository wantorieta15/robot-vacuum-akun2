**The Robot Vacuum's Best Excuse** — the funniest excuse a robot vacuum gives
for missing one spot, in a single line of at most 140 characters.

## How it works

`main.py` (pure Python stdlib, no dependencies) validates the entry — one
line, 1–140 characters, no leading or trailing whitespace, no control
characters — and writes it to `<out_dir>/entry.txt` (default `/output`),
where `<out_dir>` comes from `MAKEFUN_OUTPUT_DIR`.

## Run

```sh
python3 main.py
```

## Entry

> My timer says I clean on Tuesdays. That spot got dirty on a Wednesday. I do not work overtime for dust.
